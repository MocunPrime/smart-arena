## ISSUE-001：智慧棋盘（硬件）接入  —— `OPEN`

**背景**：会议提出三种部署方案（树莓派 / PC+蓝牙 / WiFi 棋盘 + 主机），需要把软件与实体棋盘、
OLED 屏幕联通。**当前阶段按约定先完成软件部分**，硬件（智慧棋盘）部分暂缓。

**当前状态**：软件侧仅保留**接口占位**，未接入真实硬件。

**已预留的接口**（`arena/hardware.py`）：

- `OledDisplay` / `MemoryDisplay`：显示胜率、比分、桌号；
- `BoardLink`：`MockBoardLink`（模拟）/ `SocketBoardLink`（WiFi 棋盘，TCP/IP）/ `SerialBoardLink`（树莓派串口）；
- `HardwareHub`：订阅赛事事件，驱动显示与实体棋盘。

**待办清单**：

1. 与硬件同学确认传感器 / 驱动方案与接线（会议提到 OLED 屏、面包板连线、店家提供的驱动）；
2. 实现实体棋盘坐标上报，并接入 `Tournament.play`；
3. 在 OLED 上显示实时胜率、比分与终局小结；
4. 完成三种部署方案的实测，并整理接线与部署文档。

**验收标准**：实体棋盘落子能在软件中正确反映；OLED 能实时显示胜率与终局小结。
