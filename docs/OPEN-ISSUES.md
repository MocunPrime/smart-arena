OLED 屏幕联通。**当前阶段按约定先完成软件部分**，硬件（智慧棋盘）部分暂缓。

**当前状态**：软件侧仅保留**接口占位**，未接入真实硬件。

**已预留的接口**（`arena/hardware.py`）：

- `OledDisplay` / `MemoryDisplay`：显示胜率、比分、桌号；
- `BoardLink`：`MockBoardLink`（模拟）/ `SocketBoardLink`（WiFi 棋盘，TCP/IP）/ `SerialBoardLink`（树莓派串口）；
- `HardwareHub`：订阅赛事事件，驱动显示与实体棋盘。

**待办清单**：

1. 与硬件同学确认传感器 / 驱动方案与接线（会议提到 OLED 屏、面包板连线、店家提供的驱动）；

4. 完成三种部署方案的实测，并整理接线与部署文档。

**验收标准**：实体棋盘落子能在软件中正确反映；OLED 能实时显示胜率与终局小结。

**当前状态（本次提交）**：已停用，但实现与页面完整保留。

* 总开关：`arena/venue/server.py` 中的 `VENUE_ENABLED = False`；

## ISSUE-005：改卷胜率接入 KataGo + 题库扩充  —— `OPEN`

**背景**：需求补充要求"软件要有改卷功能：人做死活题，卡塔狗计算人类落子的胜率，
连续几手胜率 90% 以上就算做对，并在网上找不同难度的死活题内置进去"。

**当前状态（本阶段已实现，可离线运行）**：

* 改卷页 `/study`、题库接口 `/api/study/problems`、做题接口 `/api/study/*` 已实现并通过测试；
* 题库：**8 道**不同难度的经典死活/杀棋常型（`arena/study/problems.py`），全部由本项目
  自带求解器与规则引擎验证"按参考解答行棋可提目标白棋"；
* 胜率：默认用**参考解答模型**（正解续着记 ≥90%，走错记 ~30%）估算，保证**无 KataGo、无外网**也能改卷；
* 判定：`QuizSession` 记录"连续做对"手数，达到本题关键手数 `streak_needed` 且目标被提即判 `solved`。

**待办清单**：

1. **接入 KataGo 真实胜率**：把 `StudyManager(evaluator=...)` 接上 `KataGoEvaluator`，
   用引擎的 `kata-analyze` 逐步胜率替换参考解答模型（接口已预留，改一处即可）；
2. **题库扩充**：当前 8 道为自研整理（避免使用授权不明的第三方习题集）；
   后续可引入**授权清晰（CC0 / MIT / 公有领域）**的真实题库，或继续自研扩充到更多难度；
3. **难度与目标多样化**：除"杀棋提子"外，补充"做活 / 双活 / 官子"等题型。

**验收标准**：接入 KataGo 后，改卷页显示的手胜率来自引擎；题库至少覆盖 4 个难度、题量充足。
